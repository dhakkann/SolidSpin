# Custom Profiles Directory

Save your AI-generated profile files in this directory.

You can paste the profile code into chat, or save it here as a `.py` file and run:
```bash
python run_py_balancer.py --profile profiles/my_profile.py
```

### Reference Examples:
- `example_archetype_a.py`: For standard single-tooth parametric discs (dictionary of radii, angles, fillets).
- `example_archetype_b.py`: For custom 2D sketch geometry (lines, arcs, multi-tooth, or cutouts) using `build123d`.
